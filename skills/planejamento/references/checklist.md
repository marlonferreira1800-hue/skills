# Checklist de planejamento

Antes de entregar o plano, verifique cada item:

## Clareza
- [ ] O objetivo final está escrito em 1-2 frases?
- [ ] O critério de "pronto/concluído" está explícito?
- [ ] As premissas estão listadas e separadas dos fatos?
- [ ] Não há informações inventadas (nomes, datas, recursos)?

## Estrutura
- [ ] O plano está dividido em fases ordenadas?
- [ ] Cada fase tem um entregável concreto?
- [ ] Cada fase tem um critério de conclusão?
- [ ] As dependências entre fases estão identificadas?
- [ ] O número de fases é adequado (nem muito granular, nem muito vago)?

## Riscos e validação
- [ ] Cada risco tem impacto e mitigação?
- [ ] Há pelo menos um checkpoint de revisão com o usuário?
- [ ] Há um "próximo passo" concreto como primeira ação?

## Proporcionalidade
- [ ] O nível de detalhe é proporcional ao tamanho da tarefa?
- [ ] Estimativas sem base estão marcadas como incertas?
